# Via Uniswap

{% stepper %}
{% step %}
### **Set Up a Wallet**

* Download and install a [**compatible wallet**](../holding/compatible-wallets.md) such as MetaMask
* Ensure your wallet is set to the [**Arbitrum One Network**](../holding/add-arbitrum-network.md) (ARB)
{% endstep %}

{% step %}
### **Fund Your Wallet**

* You'll need some USDC in your wallet, ready to trade for $AUTONOMI. If you don't have any already you can centralized exchange like [Coinbase](https://www.coinbase.com/), [BitMart](https://www.bitmart.com/), or [Binance](https://www.binance.com/), and add it to your wallet.
* You'll also need a small amount of Ethereum (ETH) for gas fees to your wallet. We recommend you start with around $10 worth of ETH.&#x20;
* Make sure you send the ETH on the **Arbitrum** network, _**not**_**&#x20;on the ETH mainnet**.&#x20;

<figure><img src="../../.gitbook/assets/image (70).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### **Connect to Uniswap**

* Visit [Uniswap](https://app.uniswap.org/)
* Click **"Connect Wallet"** and select your wallet  (e.g. MetaMask)&#x20;
{% endstep %}

{% step %}
### **Swap USDC for $AUTONOMI**

* Go to the [**AUTONOMI chart page**](https://app.uniswap.org/explore/tokens/arbitrum/0xa78d8321b20c4ef90ecd72f2588aa985a4bdb684)
* Enter the amount of USDC you want to swap for Autonomi tokens.&#x20;
* Click **"Swap"** and confirm the transaction in your wallet.In order to see the tokens in your wallet, make sure you have added the [Arbitrum One Network and imported the Autonomi token](../holding/add-arbitrum-network.md)
{% endstep %}
{% endstepper %}
