# Holding

To hold and use Autonomi Network Tokens you'll need:

* An **Ethereum wallet address.** You'll get one via your wallet app, if you don't already
* A [**compatible wallet**](compatible-wallets.md) app or hardware wallet
* To set up your wallet to work with the [**Arbitrum One network**](add-arbitrum-network.md) so you can see your Autonomi Network Tokens
